# Task 3: Short-Video Use and Academic Procrastination

## Project status and data notice

This project demonstrates a reproducible data-analysis workflow. The dataset contains 120 simulated records generated by a Python script. It does not contain responses from real students. The results below describe only the simulated dataset and must not be interpreted as evidence about university students.

## Research question

How is daily short-video viewing time associated with a simulated academic procrastination score?

## Dataset

The dataset has 120 simulated records. The main variables are:

- `daily_video_hours` — simulated hours spent viewing short videos per day;
- `simulated_procrastination_score` — simulated score from 1 to 5;
- `during_study` — whether the simulated student views short videos while studying;
- `study_year` — simulated year of study.

The data were generated with a fixed random seed so that the analysis can be reproduced.

## Data preparation

The script checks that required columns are present, removes duplicate student IDs, converts numeric variables, and keeps records with valid viewing hours and scores. It then assigns records to three viewing-time groups:

- Baseline: up to 1 hour per day;
- Middle: more than 1 and up to 3 hours per day;
- Heavy: more than 3 hours per day.

All 120 generated records were retained for the analysis.

## Analysis methods

The project calculates group means and medians, Pearson's correlation between viewing time and the simulated score, and a Welch two-sample t-test comparing the heavy and baseline groups. Two figures are created to display the simulated relationship and group score distributions.

## Results from the simulated dataset

The simulated dataset has a Pearson correlation of approximately `r = 0.308` (`p = 0.0006`) between viewing hours and the simulated procrastination score.

The mean simulated scores are approximately:

| Viewing group | Number of records | Mean score |
|---|---:|---:|
| Baseline | 32 | 2.741 |
| Middle | 81 | 3.104 |
| Heavy | 7 | 3.419 |

The Welch test comparing the heavy and baseline groups gives approximately `p = 0.099`. With a 0.05 significance level, this comparison is not statistically significant in this simulated sample.

These values are generated by an artificial data-generation process. They are not findings from an actual survey.

## Limitations

The records are simulated, not collected from real students. The outcome score is not a validated academic-procrastination scale. The artificial data-generation process deliberately creates a positive pattern, so the observed association cannot be used to support a real-world claim. The heavy-viewing group is also small (`n = 7`).

## Conclusion

The project demonstrates how to generate data, clean records, calculate summary statistics, compare groups, and create visualizations. It does not establish whether short-video use is associated with academic procrastination among real students. A real survey using an appropriate validated scale would be required to investigate that question.
